Sources and licensing
- ForeverDB.net: https://foreverdb.net/developers ; requires personal approved API key.
  60 requests/minute and 10,000/day; our client caps its calls, waits between calls,
  and shows visible attribution. Some sources reflect Classic, beta or speculation.
- AHledger: https://ahledger.com/developers ; no key required. Credit AHledger
  wherever prices are displayed; data is a historical snapshot from player scans.
- TheWoWDB: https://thewowdb.com/developers ; item reference provider.

No data providers receive FCM character names or account saved records;
only observed item IDs and manually entered item search terms are requested.
The ForeverDB key is kept exclusively in your Windows account encrypted by DPAPI
if you choose Remember. Never paste it into chat.

FCM v0.7.9: GitHub release checks use HTTPS GET against the public FCM repository.
The companion only downloads program ZIPs from that repo after user consent and verifies SHA-256.
Local character records and ForeverDB credentials are never sent to GitHub.
