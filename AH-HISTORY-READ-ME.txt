FCM - PERSONAL AUCTION HOUSE SCAN HISTORY FOLDER SETUP

1. Extract the AHHistory setup ZIP into an ordinary Windows folder.
2. Double-click SETUP-FCM-AH-HISTORY.cmd.
3. If Windows reports Access denied, right-click that .cmd and run as
   Administrator. Do not run the installer with World of Warcraft open.

The setup uses your confirmed installation path:
C:\Program Files (x86)\World of Warcraft\_forever_\Interface\AddOns\ForeverCharacterManager\AHHistory

It verifies FCM exists, then creates these folders if missing:
  Incoming
  RawScans
  Parsed
  Index
  Reports\Daily
  Reports\Weekly
  Reports\Monthly
  Logs
  Quarantine

Existing folders and files are left untouched. Running it again is safe.

NOT ENABLED: No scheduled copy of AHledger.lua, no historical scan imports,
no cleanup/retention automation, no NAS or other backup, and no restrictive
Windows permissions. We will design those separately when requested.

Store ONLY personally collected AH scans here. Do not archive downloaded
AHledger provider price tables or any expired externally sourced price data.

When updating FCM, merge the new addon files into the existing folder; do
not delete the entire ForeverCharacterManager directory first. The current
R6.1 installer explicitly excludes AHHistory from overwrites.
