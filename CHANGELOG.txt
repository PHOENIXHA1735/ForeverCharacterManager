FCM v0.7.6 - ForeverDB item-catalog and dungeon-import recovery
==================================================================

Observed user scan (Nov 10 2026): ForeverDB authenticated and returned 1,000
catalog rows, yet only 59 items were cached at the catalog stage. The sync
ended with 677 items after other sources, 2,222 recipes, 62 price records,
0 dungeon records.

Corrections:
- Save item IDs and names from common alternate/nested response shapes.
- Import ID-only catalog entries as explicitly unverified placeholders rather
  than silently losing their IDs; later item detail calls can enrich them.
- Log recognized versus returned records; stop advancing pagination cursor
  if no returned items can be saved.
- Reset the catalog and dungeon offsets to zero ONCE, recovering
  previously skipped pages.
- Recognize nested dungeon lists, instances, and alternate numeric ID fields.
- Store dungeon summary records even when a detail endpoint fails.
- Reserve request budget for dungeons before item detail/recipe loops.
- Log safe field names (not values/credentials) if an API response cannot be read.
- Preserve all settings, cached data, FCM emblem, Horde/Alliance support and
  the Stop Scan button. No change to WoW character SavedVariables.

Validation:
- ZIP integrity and static source checks completed.
- Live ForeverDB authenticated response schema and Windows PowerShell 5.1
  runtime still require verification on the user's PC.
- Source records should not be labeled confirmed Forever drops merely because
  they are present in an external catalog.
- Legacy Point automation remains deferred.

INSTALL
1. Close WoW Forever and companion.
2. Back up WTF and the ForeverCharacterManager folder.
3. Extract ZIP; merge ForeverCharacterManager folder into
   ...\World of Warcraft\_forever_\Interface\AddOns\
   Choose Replace; do not delete original folder first.
4. Open ForeverCharacterManager\FCM-Companion\OPEN-FCM-DATA-UPDATER.cmd
5. Click Scan + Update Data, then inspect the catalog and dungeon totals.

NEVER share the API key, settings.json, or DPAPI credential file.
