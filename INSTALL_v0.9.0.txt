FCM v0.9.0 CONSOLIDATED RELEASE — INSTALL

To install in WoW:
1. Completely close WoW and the Windows companion.
2. Back up your existing Interface/AddOns/ForeverCharacterManager folder and SavedVariables/FCM_DB.lua.
3. Extract the source ZIP in a temporary folder.
4. Copy the ForeverCharacterManager folder into your Interface/AddOns folder, merging and replacing matching addon files. Do not delete your existing folder.
5. Do not delete SavedVariables, ExternalData.generated.lua, AHPrices.generated.lua or local companion data.
6. Log each character in/out normally to update their identity snapshot.
7. Verify FCM v0.9.0 and build Release-20261112-Consolidated in Diagnostics.

To publish GitHub: use the separate Publish-FCM-v0.9.0.ps1 PowerShell script with Git for Windows. The ZIP is source, not personal data.
