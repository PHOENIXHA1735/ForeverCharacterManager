ONE-WORD INSTALLATION
1. Completely exit World of Warcraft (do not install while logged in).
2. Extract this ENTIRE ZIP to a normal Windows folder.
3. Double-click INSTALL-FCM-R61-Cleanup.cmd.
4. The installer detects your existing FCM installation automatically. Your
   confirmed default location is:
   C:\Program Files (x86)\World of Warcraft\_forever_\Interface\AddOns
5. Confirm the destination shown, then type INSTALL. No path entry is needed
   when the default or last-used installation is valid.
6. Reopen WoW, type /fcm, check Diagnostics for the R6.1 build ID.

If you move WoW or install FCM in a different location, the installer checks
other common drive paths. If it finds more than one valid installation with
no remembered choice, it asks which one you want. If none are found, paste
the path one time; it is remembered after a successful install in:
%LOCALAPPDATA%\FCM-Installer\AddOnsPath.txt
Only the installer changed in this ZIP. The addon is the same R6.1 build.
