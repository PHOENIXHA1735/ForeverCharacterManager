# Forever Character Manager (FCM)

An account-wide character management addon for World of Warcraft: Forever.

FCM supports Alliance and Horde characters, equipment upgrades, professions, crafting, inventory tracking, talent builds, dungeon loot research, and external reference-data integration.

Includes a Windows Data Companion for reference-data synchronization and GitHub-based updates.
